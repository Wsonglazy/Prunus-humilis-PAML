# PAML Analysis Files for *Prunus humilis*

This repository contains the files required to reproduce and verify the PAML-based positive selection analyses conducted for the mitochondrial genome of *Prunus humilis*.

## Contents

- `alignments/`: Gene alignment files used in the analyses.
- `trees/`: Phylogenetic trees used by PAML.
- `control_files/`: PAML control files and model settings.
- `original_outputs/`: Original analysis outputs and log files.

These materials are provided to facilitate independent verification of the analyses and the results reported in Tables 3 and S7 of the associated manuscript.
